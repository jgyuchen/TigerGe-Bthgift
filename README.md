## 🚀 Deployment

1. Create a new GitHub repository (e.g. `BirthdayTiger`)
2. Upload `index.html` as the root file
3. Go to **Settings → Pages → Source: Deploy from a branch → Branch: main → /(root) → Save**
4. Live link: `https://[your-username].github.io/BirthdayTiger`
